WHAT THIS IS

            

              A lab for LSB steganography in PNG pixels. The least significant bits of R/G/B
              hold a tiny payload. At 1 bit/channel a photo looks unchanged. This is for learning — not a
              covert-comms kit.
            

          

          

            
CARRIER

            

              Drag to pan, mouse wheel to zoom (pixelates past 150% so you can inspect LSBs). FIT frames
              the carrier. SNAP copies the current pixel size into W×H; RESIZE resamples
              the loaded carrier to that size (this destroys any embedded payload). Set W × H
              (16–4096) before SYNTH SAT or GPT GEN. JPEG/WebP are accepted as input; export is always lossless PNG.
              Remote URLs often fail CORS — save locally if PULL is blocked.
            

          

          

            
VIEWS

            

              SRC original · STEGO after embed · LSB amplified
              bit-plane · DELTA original vs stego. Loading a PNG that already has a
              DDRP frame strips those LSBs into SRC and opens on STEGO so LSB/DELTA
              work immediately.
            

          

          

            
GPT CARRIER

            

              Toggle GPT on the payload strip. The box becomes a prompt. GPT GEN
              calls OpenAI gpt-image-1 with the key from the local [stegano] creds block
              (server-side only). Photos with grain and detail hide LSBs better than flat graphics. After it lands,
              switch back to MSG and type the payload to embed.
            

          

          

            
BINARY / AUDIO

            

              Toggle BIN, load any file (wav, mp3, pdf, zip…). A tiny DDFILE header
              plus the raw bytes go into the LSBs — no Base64 on the file itself (UTF-8 is only
              for text messages).               Extract (and LIB → OUTPUT) restores the original bytes and reconstructs a preview —
              audio player, nested image, video, or PDF — while keeping the DDFILE header and hex dump.
              A key encrypts those bytes with OpenSSL first. Scaling the carrier after embed will destroy
              the file.
            

          

          

            
PAYLOAD PIPE

            
No key: TEXT → LSB or FILE → LSB.

            
With a key: … → openssl enc → LSB (OpenSSL’s own Base64 is only on the ciphertext).

            

              The frame prefix is DDRP + 32-bit length, then raw payload bytes, walking
              pixels left-to-right, top-to-bottom. Extract must use the same bits, channels, cipher, and key.
            

          

          

            
OPENSSL

            

              Ciphers come from openssl enc -ciphers on this machine. Key wrapping modes are
              omitted (they are not for arbitrary text). Legacy toys (DES, RC4, Blowfish…) load via the
              OpenSSL 3 legacy provider. Default KDF: -pbkdf2 -iter 10000, Base64 with
              -a -A (no line wraps).
            

            
printf '%s' 'hello' | openssl enc -aes-256-cbc -e -a -A -pbkdf2 -pass pass:KEY
openssl enc -aes-256-cbc -d -a -A -pbkdf2 -pass pass:KEY

            

              ECB and RC4 are in the list so you can see why they are poor choices. Prefer AES-*-CBC/CTR or
              ChaCha20 for the lab default.
            

          

          

            
LIBRARY

            

              Carriers land in images/source/ (GPT working size, SYNTH, local/URL loads, resizes).
              Stego frames land in images/output/ on EMBED. A second save with the same name,
              pixel size, and payload is skipped. Open LIB to browse either reel and click a
              still to load it. Scratch files you plan to hide live in payloads/.
            

          

          

            
KEEP IT

            

              Embed writes images/output/. EXPORT PNG only downloads — it does not
              make a second copy. Reload from LIB, set the same cipher/key, and EXTRACT. WIPE restores the
              carrier and clears the message (not the key).
